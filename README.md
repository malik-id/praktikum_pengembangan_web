# praktikum_pengembangan_web
Repo ini digunakan untuk keperluan praktikum pengembangan web kolaborasi.

### Langkah-langkah Sinkronisasi Git:
1. Menambahkan file ke staging area:
   ```bash
   git add sinta.html
   ```
2. Menyimpan perubahan dengan pesan commit:
   ```bash
   git commit -m "tambah sinta.html"
   ```
3. Mengunggah file ke repositori online GitHub:
   ```bash
   git push
   ```
